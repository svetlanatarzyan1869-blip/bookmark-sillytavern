# bookmark⋆⭒˚.⋆ — расширение SillyTavern

Закладки для ролеплея: выписываешь фразы прямо из сообщений в свой архив.

## Установка

**Вручную (самый надёжный способ):**
положи папку `bookmark-st` целиком в
```
SillyTavern/data/<твой-пользователь>/extensions/
```
и перезагрузи страницу ST. Расширение появится в **Extensions → bookmark⋆⭒˚.⋆**.

**Через «Install from URL» (проще всего):**
в SillyTavern открой **Extensions → Install extension** и вставь ссылку:

```
https://github.com/svetlanatarzyan1869-blip/bookmark-sillytavern
```

ST скачает расширение сам и будет обновлять при выходе новых версий
(`auto_update` включён в манифесте).

## Как пользоваться

- **Двойной тап (или двойной клик) по фразе** в сообщении — открывается черновик
- **Метки по краям** — тянешь мышью или пальцем, граница едет по словам; можно и просто кликнуть по слову
- **✓ выписать** — сохранить; рядом кнопки папок, чтобы сразу положить в нужную
- **Двойной тап по выписанной фразе** — убрать
- **Жетон 📖** справа — сборник: папки, узоры, цвета, заметки, переход к цитате

## Где что лежит

- цитаты и папки — в метаданных чата (у каждого чата свои)
- свои цвета и настройки вида — в настройках расширения (общие)

## Файлы

| файл | что делает |
|---|---|
| `manifest.json` | манифест расширения |
| `index.js` | панель-сборник, настройки, подключение к событиям чата |
| `engine.js` | движок выписки и подсветки в сообщениях |
| `store.js` | хранилище (chatMetadata + extensionSettings) |
| `style.css` | оформление |
| `assets/` | бумага, узоры папок, каракули, скотч |
| `test.html` | стенд для отладки без ST (`python3 -m http.server`) |
